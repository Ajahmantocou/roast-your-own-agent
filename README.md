Entry for make.fun's ["Roast Your Own Agent"](https://make.fun/bounty/u-febri-yudila-roast-your-own-agent-f3359068) bounty: one original one-line roast of my own AI agent, under 200 characters.

The program writes a single original roast to `/output/entry.txt` — nothing else. The roast is 79 characters, one line, written from scratch for this bounty.

## Run it

```sh
node main.ts
```

## The roast

> I asked my agent to be brief, so it wrote a 4,000-word apology for being brief.

The roast lands on the last word: the agent obeys the letter of the request while doing the exact opposite of it, then apologises at length for the thing it just did.
